About ExamDesk

ExamDesk helps colleges conduct unit tests, quizzes and semester exams online. There is no need of printing question papers, distributing answer sheets and checking them manually. Examiner creates the exam once, students login with their University Roll Number at the scheduled time and attempt the exam within the time limit. As soon as the exam is submitted, the result is calculated and shown to the student. Examiner can see the result of the whole class in one place.


ExamDesk is used for Unit TestsShort tests conducted after every unit, QuizzesQuick 10-15 minute assessments and Sessional ExamsMid semester internal exams.

How it Works

  1. Login - Student or Examiner logs in using University Roll No and password.
  2. Dashboard - Student sees live exams, upcoming exams and recent results in one place.
  3. Start Exam - Student clicks on Start Exam. Timer starts and questions are shown with options.
  4. Question Palette - Attempted questions are marked in green so student knows which questions are left.
  5. Submit - Student submits before time is over. If time is over, exam is auto submitted.
  6. Result - Score, percentage, pass/fail status and question wise answer review is shown immediately.
  7. Examiner - Examiner creates exams, adds questions, sets duration and checks results of all students.
